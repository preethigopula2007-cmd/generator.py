# 🔐 PASSWORD-GENERATOR

A secure and customizable random password generator built using Python.

### ✨ Features
- 🔢 Set your own password length
- 🔠 Includes uppercase, lowercase, numbers & symbols
- 🎲 Generates strong & random passwords instantly
- User-friendly CLI interface

### 💻 Tech Stack
- Python 3
- `random` and `string` modules

### 🚀 How to Run
1. Clone the repository
2. Run `python generator.py`
3. Enter desired length and get your password!
